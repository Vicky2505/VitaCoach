# 🧘‍♀️ Personalized Wellness and Disease Prevention Coach

An AI-powered mobile app that helps users take control of their health through **personalized wellness tasks**, **preventive care insights**, and **gamified activities** — all based on their unique health data.

---

## 🚀 Overview

**Personalized Wellness and Disease Prevention Coach** is a mobile app designed to guide users toward a healthier lifestyle using AI. It provides daily personalized recommendations like:

- 🥗 Diet Tips  
- 🏃 Exercise Suggestions  
- 😴 Sleep Advice  
- 💧 Hydration Reminders  

The app also motivates users with a **gamified system**, awarding points and badges for completing health tasks.

---

## 🧠 Key Features

### 🤖 AI Health Profile Generator
- Analyzes user inputs (e.g., age, health records, lifestyle habits).
- Builds a personalized health profile using AI.

### 📅 Daily Wellness Engine
- Suggests daily goals and activities based on user profile.
- Adjusts over time with behavior tracking.

### 🎮 Gamified Wellness Journey
- Earn XP, rewards, and badges.
- Stay motivated with streaks, levels, and community challenges.

### 📊 Progress & Insights
- Visual dashboard to track daily, weekly, and monthly progress.
- Insightful health trends and personalized feedback.

---

## 🛠️ Tech Stack

- **Flutter** – Cross-platform mobile development.
- **Firebase / Supabase** – User authentication and real-time data.
- **OpenAI / LLM (Pluggable)** – AI-driven profile and suggestions.
- **Hive / SharedPreferences** – Local storage for offline support.
- **Provider / Riverpod** – State management.
- **Custom Gamification Engine** – Built to handle health tasks, points, and rewards.
